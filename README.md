# StarGazer — Movie Recommendation System

An undergraduate movie recommendation project combining **genre-based filtering, sentiment analysis, and emotion analysis** to create more personalized movie discovery.

## 🎯 Project Overview

StarGazer explores how user reviews and movie metadata can support recommendation beyond simple ratings.

### Core ideas
- Movie metadata and descriptions
- User-review analysis
- Sentiment classification
- Emotion analysis
- Genre-specific recommendation
- Explainable AI concepts
- Flask-based web application

## 🧠 Technical Approach

The project explores:
- Logistic Regression
- Support Vector Machines (SVM)
- NLP preprocessing
- Sentiment analysis
- Emotion classification
- GPT-based experimentation
- SHAP / LIME for explainability

## 🏗️ Application

The Flask application supports filtering by:
- Movie title/search term
- Minimum rating
- Genre
- Emotion
- Sentiment

## 🛠️ Technology Stack

Python · Pandas · NumPy · Scikit-learn · NLP · GPT experimentation · SHAP · LIME · Flask · HTML/CSS
